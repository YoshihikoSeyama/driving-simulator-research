# 運転シミュレーション調べ

運転シミュレーション（ドライビングシミュレータ）に関する調査メモをまとめるリポジトリ。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `notes/` | 調査メモ。1トピック1ファイル（Markdown） |
| `references/` | 参考文献・リンク集、引用元の整理 |
| `data/` | 収集したデータ、スペック表、比較表など |
| `assets/` | 画像・図・スクリーンショット |

## メモの書き方

- ファイル名は `YYYY-MM-DD-トピック.md` の形式にする
- 各メモの先頭に、調べた日付・目的・情報源を書く
- 出典URLは必ず残す（後から確認できるようにする）

## 進捗

- [ ] 調査の目的と範囲を決める
- [ ] 候補となる製品・ソフトウェアの洗い出し
- [ ] 比較軸（価格・機能・対応ハード・用途）の整理
- [ ] まとめ
