# 質問ストック ― 一般ユーザーが言語化できていない「本当は知りたいこと」

- 開始: 2026-08-14
- 目的: ユーザーが自分では質問の形にできない疑問を生のまま蓄積し、
  調査・構造化して能動型AIの出力元にする
- 位置づけ: `2026-08-14-後悔カタログ-車のライフサイクル.md` の姉妹ファイル

## 2つのカタログの違い

| | 後悔カタログ | **質問ストック（本ファイル）** |
| --- | --- | --- |
| 中身 | 事後に判明した損失 | **事前に持っている素朴な疑問** |
| 集め方 | 体験後にヒアリング | **痛みを持つ人が生のまま吐き出す** |
| トリガー | イベント・カレンダー | 検討フェーズ・状況 |
| 出口 | 能動通知 | **段階的な質問 → 個別化された回答** |

両方が同じ製品の原資になる。後悔カタログは「黙っていると損する」を、
質問ストックは「聞けないから辿り着けない」をカバーする。

## 記入ルール

- **生の問いはユーザーの言葉のまま残す**（整形すると意図が飛ぶ）
- 1問1エントリ。複合質問は分解する
- ステータス: `未調査` / `調査中` / `調査済` / `保留`
- **鮮度**を必ず付ける（この情報は何ヶ月で腐るか）。定期更新の設計に使う

## Q001. 予算起点で「何が可能か」を知りたい

**生の問い**
> レンタカーのことで料金別でどんなことが可能になるのか、15000円だとこのレベルの車を
> どれくらいとか、20000円だとこのレベルの車をどれくらいの長さ借りれるのかとか

**本当に知りたいこと**
予算という制約から出発して、「車のグレード × 借りられる日数」のトレードオフを俯瞰したい。
「この予算だと現実的にどこまでできるのか」の相場観。

**なぜサイトで解決しないか（★重要な構造的発見）**
既存のレンタカー予約サイトは全社 `日時 → 場所 → クラス → 料金` の順で、
**予算を入力する欄が存在しない。** ユーザーは逆順（予算 → 可能性）で考えているのに、
その入口がないため**質問として成立できていない。**

**必要なデータ**
- 会社 × クラス × 期間 の料金表（12時間/24時間/以降1日ごとの逓減構造）
- 免責補償・NOC補償込みの実質価格
- 地域差・シーズン差の係数
- 長期割引（3日以上、1週間、1ヶ月）の段差

**出力イメージ**
```
予算 15,000円 でできること（東京・平日・補償込み）
  軽自動車      → 3日間
  コンパクト    → 2日間
  ミニバン      → 1日（+乗り捨てなし）
  ※ 沖縄の8月なら上記から1日減る
```

**鮮度**: 料金改定は年1〜2回。**四半期ごとの更新**が必要。繁忙期係数は毎年
**ステータス**: **調査済** → `2026-08-15-レンタカー料金の構造と予算逆引き.md` 第6章に逆引き表あり

**調査で判明した重要な点**
- **線形計算すると必ず過小評価になる。**2日目以降は逓減する（×0.70〜0.85）
- **補償は定額なので安いクラスほど相対負担が重い**（軽で20%、格安の12時間なら31%）。
  **看板価格での逆引きは詐欺的になるため補償込み表示が必須**
- 15,000円（東京・平日・通常期・補償込み）の実際: **軽2日が15,300円で300円超過**、
  コンパクト1日10,150円、ミドル1日12,650円、**ミニバンは1日18,200円で届かない**

## Q002. 長さと料金の関係はどこで得になるのか

**生の問い**（Q001から分解）
> 20000円だとこのレベルの車をどれくらいの長さ借りれるのか

**本当に知りたいこと**
料金は日数に比例しない。**どこに段差があるのか**を知りたい。
「あと1時間で1日分取られる」「3日目から急に安くなる」のような境界。

**なぜサイトで解決しないか**
料金表は載っているが、**逓減の構造が可視化されていない。**
自分で複数パターンを検索して比較しないと分からない。

**必要なデータ**
- 6時間/12時間/24時間/以降24時間ごと の料金刻み
- 超過料金の単価と「1日分に切り替わる」閾値
- 長期割引の発動日数

**鮮度**: 料金体系の変更は稀。**年1回**で足りる
**ステータス**: **調査済**（一部未確認）

**判明した段差**
- 刻みは全社共通で `6h → 12h → 24h → 以後1日 → 以後1時間`
- **超過は「以後1日」と「以後1時間×n」の安い方が自動適用される**（トヨタ公式が明記）。
  ニッポンの試算では**約6時間超過で1日料金に切替**
- **最大の段差はウィークリープラン（×0.33）。**3日以上なら週単位の方が安いケースがある
- **ニコニコレンタカーだけ逓減しない**（24h+12hの単純加算）＝長期ほど大手に対する優位が縮む
- ⚠ **明示的な日数パック（3日/5日）の有無は確認できず**

## Q003. 安くする方法（豆知識）

**生の問い**
> それに付随してなんか豆知識的なものはないか？安くする方法とか

**本当に知りたいこと**
同じ条件でも支払額を下げられる操作があるなら知りたい。
「知っている人だけが得している」類の情報。

**既に判明している材料**（前回調査より）
- **免責補償込みプランを選ぶと実質無料**になる（タイムズ・オリックスが常時展開）
- **乗り捨ては10km以内ならほぼ無料。トヨタのみ同一都道府県内が無料**
  （東京〜静岡で会社間1万円以上の差）
- **北海道は「道トクふりーぱす×レンタカーセットプラン」で道内高速4日間7,700円。
  ただし事前申込制で当日は買えない**
- 沖縄の繁忙期は**3か月前予約で直前比20〜30%安**
- **キャンセルは7日前まで無料**が大手の標準（ガッツ・業務レンタカーは3日前まで無料）

**調査で追加された材料**
- **★ ハイシーズンは「出発日」で期間全体が決まる**（ニッポン・ニコニコが明記）。
  **1日ずらすだけで全日程の単価が変わる。既存のどの予約サイトにもない機能になる**
- **割引は併用不可。**トヨタはJAF・会員・カード・特割GO!が**選択適用**
  → **足し算UIを作ると破綻する。max演算にすること**
- 割引率の実測: ニッポンJAF **−41%**（業界最大）／ニッポン早割45 **−40%**／
  トヨタ特割GO! **−30%**／タイムズクラブWeb **−20%**（大手の会員制度では最大）
- **早割と柔軟性はトレードオフ**。ニッポン早割45は**45日前以降 予約変更不可**。
  一方**タイムズクラブは出発24時間前まで無料キャンセル**（非会員は7日前）
  → 早割を「無料の価格オプション」に変えられる
- JAF年会費4,000円は**年1〜2回の利用で元が取れる**
- 比較サイトは**一律にどちらが安いとは言えない**（出発地・日時・クラスで逆転）。
  たびらいは**補償込みのコミコミ価格を最初から表示**
- **楽天のクーポンとレンタカー会社のクーポンは併用可**。配布は**月初とスーパーSALE前**が多い
- 時間の裏技: **「24時間＋時間延長」<「2日分」**が成立する。申告時間を刻めば自動最適化される

**まだ未調査**
- 空港店 vs 市内店の価格差（**検索では出ない。実際に両方見積もるしかない**）
- 株主優待・クレカ優待の具体的な割引率
- マンスリー料金の実額（大手はWeb非公開、営業所への電話が必要）

**鮮度**: キャンペーンは**月次で変わる**。制度系（乗り捨て・周遊パス）は年1回
**ステータス**: 調査済 / 一部未確認
